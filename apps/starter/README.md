# Starter

Toolchain and hardware check, and the template that `make new` copies.

```sh
make APP=starter program-dfu
```

## Controls

| Control | Function |
|---|---|
| Knob 1 | Low-pass cutoff, 20 Hz - 18 kHz (exponential) |
| Knob 2 | Output level |
| Button 1 | Bypass (LED 1: green = active, red = bypassed) |
| LED 2 | Blinks to show the main loop is running |
